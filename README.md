## 四、技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤；
- **零第三方库**（未使用 Bootstrap、Element Plus、Ant Design 等预设样式/组件库，也无功能性库需要列明）；
- 图形全部为项目内原创 SVG，运行时由 `js/art.js` 绘制；
- 内容数据集中在 `js/data.js`，两个模式共用；
- 无后端：收藏卡在浏览器本地用 Canvas 生成并下载；
- 界面规格：1920 / 1440 / 720（另适配手机宽度）；运行环境 Chrome 129；正常网速与慢网测试；
- 无外部图片/字体请求，适合慢网。
